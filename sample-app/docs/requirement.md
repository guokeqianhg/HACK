# 需求文档：迷你电商「下单 / 优惠券」

> 本文件作为「AI 测试官」场景 B（需求文档 → 验证实现）的输入。

## 1. 商品与购物车
- 系统展示商品列表（名称、单价、库存）。
- 用户可将商品加入购物车，购物车显示每项数量与小计，并汇总总价。

## 2. 优惠券
支持三类优惠券，且可叠加使用（每类最多 1 张），叠加顺序为：满减 → 无门槛 → 折扣。
- **满减券**：订单金额达到门槛后，立减固定金额；未达门槛则该券不生效。
- **无门槛立减券**：直接立减固定金额，无门槛限制。
- **折扣券**：在前面减完后的金额基础上，按比例减价（例如 9 折 = 减 10%）。
- 最终应付金额不低于 0。

## 3. 下单
- 提交订单时，系统先校验库存，库存不足则下单失败并回滚已扣库存。
- 下单成功返回订单号、原价、应付金额、已应用/被拒绝的优惠券明细。

## 4. 金额精度
- 所有金额以「分」为整数单位计算，避免浮点误差；前端展示时格式化为「¥x.xx」。

## 5. 边界与异常
- 空购物车不可下单。
- 库存并发扣减应安全（当前版本为单进程内存实现，未处理并发，列为已知风险）。
