全链路自动化测试 Agent

高级选项（可选）
webhook 地址仅用于本次运行，不会写入报告或日志。长期推送建议在服务端配置环境变量 WEBHOOK_URL。

仓库需公开可 clone（内网/私有仓库沙箱访问不到）；被测项目建议为可 node --test 的 Node 仓库。 真实跑测通常需数十秒~一两分钟。
